# For AI agents

This is the **Playwright POM Harness** — a portable, versioned Claude Code harness
(convention skill library + lifecycle hooks + ADO pipeline scripts) for
Playwright/TypeScript Page-Object-Model test-automation repos.

If you are an AI agent asked to install, adopt, or update this package in a repo:
follow the **"For AI agents: adoption protocol"** section of [README.md](README.md)
exactly — it defines orientation (fresh repo vs existing framework), the hard rules
(merge-never-overwrite, package `VERSION` ownership, derive-only team libraries,
baseline discipline), the verification gates, and the report format.

After adoption, the repo's `CLAUDE.md` plus `.claude/skills/` become your operating
contract there: skill-first routing for every framework task, feature branches only,
delivery through pull requests.
