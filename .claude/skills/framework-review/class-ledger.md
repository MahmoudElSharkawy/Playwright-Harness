# Framework review finding classes

This package starts with an empty review ledger. Consumer repositories may record
sanitized finding classes after independent review. Do not copy private incidents,
credentials, customer identifiers or historical delivery records into this file.

## Rule proposals

When a class recurs three times, propose a narrowly scoped check with positive and
negative fixtures. A proposal is not automatic permission to change conventions.
Do not expand the conventions baseline to conceal a newly introduced violation.
